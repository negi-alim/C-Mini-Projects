# C Mini Projects

A collection of **over 40 C programming exercises and mini projects** developed as part of my university coursework and programming practice.

All programs in this repository were **written entirely from scratch without AI assistance in their implementation or algorithms** and cover a variety of fundamental programming concepts, algorithms, data structures, and small interactive projects.


## Repository Structure

The programs are organized into folders based on the main concepts they cover:

| Folder | Description |
|---|---|
| **Arrays** | Exercises involving one-dimensional and two-dimensional arrays, searching, sorting, and array manipulation. |
| **Console Animation And Patterns** | Console-based animations, character patterns, and output formatting exercises. |
| **Linked List** | Exercises focused on creating, traversing, modifying, and managing linked lists. |
| **Mini Games** | Small console-based games developed to practice programming logic and interactive input. |
| **Others** | Miscellaneous exercises that do not fit into the other categories, including topics such as number systems, time and date, and basic algorithms. |
| **Strings** | Exercises involving string processing, character manipulation, searching, conversion, and frequency analysis. |
| **Structures** | Programs using C structures to organize and process related data. |

Each folder contains a separate `README.md` file with a brief description of the topic and an overview of the programs included in that category.

## Requirements

Most programs can be compiled using a standard **C compiler**, such as GCC.

Some programs were originally developed and tested in a specific university/lab environment and may use platform-specific libraries or functions such as `conio.h`, `unistd.h`, or `system("cls")`. These programs may require minor modifications to run on other operating systems.

## Notes

This repository primarily serves as an **academic archive and programming practice collection**. The exercises range from basic programming concepts to more complete mini projects.

The projects are organized by topic to make the progression and different areas of C programming easier to explore.
