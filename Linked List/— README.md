# Linked List

This folder contains C programs that explore **singly linked lists** and their fundamental operations. The programs demonstrate dynamic node creation, linked-list traversal, insertion, deletion, pointer manipulation, and using linked lists to process character sequences.

## Programs

### Linked-List-Insertion-Before-Character.c
This program creates a singly linked list from the characters entered by the user and provides functions for displaying the list, removing a node following the character `c`, and inserting a `#` node before a node containing `c`. The program demonstrates dynamic node creation, linked-list traversal, insertion, and deletion.

### Linked-List-Character-Deletion.c
This program creates a singly linked list from an input string and removes the node that follows a node containing the character `c`. It then displays the resulting linked list, demonstrating dynamic node creation, linked-list traversal, node deletion, and pointer manipulation.

### Linked-List-Insertion-and-Deletion.c
This program builds a singly linked list from user-provided integers and performs two operations based on the value `4`. It inserts a new node containing `8` before a node containing `4`, then removes the node following a node containing `4`. The program demonstrates linked-list construction, traversal, insertion, and deletion.

### Linked-List-Node-Deletion.c
This program creates a singly linked list from a string entered by the user and removes the node that follows a node containing the character `c`. It then displays the resulting linked list, demonstrating dynamic memory allocation, linked-list traversal, pointer manipulation, and node deletion.

### Reverse-String-Using-Linked-List.c
This program reads a string and uses a singly linked list to reverse the order of its characters. Instead of appending new nodes to the end, each new character is linked to the beginning of the existing list, resulting in the reversed string when the list is displayed.
