# Structures

This folder contains C programs focused on **structures and structured data**. The programs demonstrate how structures can be used to group related information, store collections of records, process student data, and work with multiple fields of different data types.

## Programs

### Bank-Account-Structures.c
This program uses C structures to store basic information for two bank accounts, including account IDs, CVV2 values, expiration dates, and credit amounts. It reads the information for both accounts and adds the credit of the first account to the second account's credit. It demonstrates structure definitions, structure variables, user input, and accessing structure members.

### Student-Information-Using-Struct.c
This program stores information for a user-defined number of students using a C structure. For each student, it collects the first name, last name, student ID, and score, then displays the stored information. It demonstrates structure definitions, arrays of structures, functions, user input, and accessing structure members.

### Student-Information-Using-Struct-Second-Version.c
This program stores information for multiple students using a C structure and compares their first names to determine maximum and minimum values according to string comparison results. It uses an array of structures, separate input and processing functions, and the `strcmp` and `strcpy` functions to work with student names.

### Student-Records-Sorted-by-ID.c
This program stores the name, score, and student number of ten students using C structures. It then searches through possible student numbers in descending order and displays the corresponding student records, effectively presenting the students according to their student numbers. It demonstrates structures, user input, conditional statements, loops, and record organization.
