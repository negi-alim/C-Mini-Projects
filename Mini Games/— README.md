# Mini Games

This folder contains small **console-based games written in C**. The programs focus on basic game logic, random number generation, user interaction, loops, and conditional statements. These projects were developed as programming practice and demonstrate how fundamental C concepts can be used to create simple interactive games.

## Programs

### Number-Guessing-Game.c
This program generates a random number and asks the user to guess it. After each incorrect guess, it provides a hint indicating whether the target number is higher or lower and continues accepting guesses until the correct number is entered. It demonstrates random number generation, loops, conditional statements, and user input.

### Random-Number-Risk-Game.c
This program is a simple risk-based number game in which the player repeatedly generates random numbers and adds them to a running total. The player can continue generating numbers or stop and compare the final total with a randomly generated computer number. If the player's total exceeds 101, the player loses; otherwise, the final comparison determines the winner.
