# Console Animation And Patterns

This folder contains C programs that generate different **console-based visual patterns and animations** using characters such as letters, spaces, and asterisks. The programs demonstrate the use of loops, nested loops, formatted console output, and basic screen manipulation to create static patterns and simple animations.

## Programs

### Alphabet-Triangle-Pattern.c
This program reads an English alphabet character and prints the alphabet in an increasing triangular pattern starting from the entered character. It supports both uppercase and lowercase letters and validates the input before generating the pattern.

### Console-Star-Animation.c
This program creates a console animation of a star-shaped figure resembling an arrow that moves across the screen. The animation is divided into four sequential steps, moving the figure horizontally and vertically while repeatedly clearing and redrawing the console. It demonstrates nested loops, console output, and basic screen-based animation.

### Decreasing-Right-Aligned-Star-Pattern.c
This program reads an integer and prints a decreasing right-aligned star pattern. Each row contains fewer stars than the previous row while the number of leading spaces increases. It demonstrates nested loops and formatted console output.

### Right-Aligned-Star-Pattern.c
This program reads an integer and prints a right-aligned rectangular star pattern. It uses nested loops to control the number of stars and leading spaces in each row, creating a progressively shifted pattern in the console.
