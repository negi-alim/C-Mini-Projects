# Others

This folder contains C programs that cover a variety of **programming exercises and fundamental concepts** that do not fit into the other categories of the repository. The programs include basic simulations, date and time calculations, and prime-number detection, demonstrating the use of loops, conditional statements, arithmetic operations, and standard C library functions.

## Programs

### Coin-Toss-Probability-Simulation.c
This program simulates different distributions of heads and tails in a fixed number of coin tosses. For each iteration, it calculates the number of heads and tails, updates a running balance for each result, and displays the difference between the two outcomes. It demonstrates the use of loops, integer calculations, and basic simulation concepts.

### Current-Date-Calculator.c
This program calculates and displays the current date using the Unix timestamp returned by the `time()` function. It determines the year, calculates the number of elapsed days in the current year, and uses conditional statements to identify the corresponding month and day. It demonstrates time handling, integer arithmetic, loops, and conditional logic.

### Four-Digit-Prime-Numbers.c
This program finds and displays all four-digit prime numbers. It checks each number from 1000 to 9999 and tests whether it is divisible by any integer other than 1 and itself. It demonstrates nested loops, divisibility checks, conditional statements, and basic prime-number detection.
